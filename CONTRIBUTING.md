# Contributing to Codemaster-AI

Thank you for your interest in contributing to Codemaster-AI! We appreciate your help in making this a powerful, privacy-first, local-first AI coding agent.

## 🚀 Quick Start for Contributors

### Prerequisites
- **Python 3.10+ / 3.11+**
- **Docker & Docker Compose** (for Ollama LLM orchestration and containerized services)
- **Git**
- **GitHub CLI** (optional, for local actions testing via `act`)

### Development Setup
1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/sharfuddin18/Codemaster-Ai.git](https://github.com/sharfuddin18/Codemaster-Ai.git)
   cd Codemaster-Ai

## Pull Request Checklist

Before opening a pull request, confirm:

- [ ] The change is focused and related to the stated purpose.
- [ ] Existing functionality has been tested.
- [ ] New behavior has appropriate tests when applicable.
- [ ] Documentation has been updated when necessary.
- [ ] `git diff --check` passes without errors.
- [ ] No secrets, credentials, tokens, or private configuration files are included.
- [ ] The pull request description explains what changed and how it was tested.

## Review Guidelines

Pull requests should be reviewed for correctness, maintainability, security, documentation quality, and compatibility with the existing project architecture. Keep reviews constructive and focused on improving the project.
